# Ecosystem

#ttrpg #tools #ecosystem #digital

Gryst isn't just a rulebook — it's designed with a digital-first toolkit in mind. While you can absolutely play with paper, dice, and imagination, these companion tools unlock the full potential of momentum-based play.

---

## The Vision

```
┌────────────────────────────────────────────────────┐
│                    ECOSYSTEM                        │
│                                                    │
│  ┌─────────────┐         ┌─────────────────────┐   │
│  │     PDA     │◄───────►│ Mundi et Caeli      │   │
│  │             │         │     Grystis         │   │
│  │ • Sheets    │         │                     │   │
│  │ • Momentum  │         │ • 3D Environment    │   │
│  │ • DM Tools  │         │ • Real-time Author  │   │
│  │             │         │ • Tabletop Sim      │   │
│  └─────────────┘         └─────────────────────┘   │
│        ▲                          ▲                │
│        │      ┌──────────┐        │                │
│        └──────│ Players  │────────┘                │
│               └──────────┘                         │
└────────────────────────────────────────────────────┘
```

**PDA** handles the mechanical bookkeeping — character sheets, momentum tracking, dice resolution. It's the "brain."

**Mundi et Caeli Grystis** handles the spatial reality — 3D environments, tactical positioning, visual storytelling. It's the "world."

Together, they create a seamless digital tabletop experience where the DM can sketch a castle into existence while the system tracks everyone's momentum automatically.

---

## Tools at a Glance

| Tool | Platform | Purpose |
|------|----------|---------|
| **PDA** | Web, Desktop (Electron), Mobile | Character sheets, momentum tracking, DM dashboard |
| **Mundi et Caeli Grystis** | Desktop (Unity) | 3D tabletop simulation with real-time world authoring |

Both tools can be used independently or together. PDA is the lightweight option for theater-of-mind play; Mundi brings the full 3D tactical experience.

## Business Model

Gryst is built on a **free core, premium extras** philosophy. The rules should never be paywalled.

### Always Free

| What | Description |
|------|-------------|
| **PDA App** | Full app — character sheets, momentum tracking, DM tools, basic 3D tactical view |
| **Core Rules** | Complete ruleset accessible within PDA — everything you need to play |
| **Community Content** | Player-created campaigns, homebrew, etc. |

**The principle:** If you need it to play, it's free. No "buy the rulebook to learn how momentum works."

### Paid Products

| What | Description |
|------|-------------|
| **Physical Rulebook** | Premium printed book with full art, worldbuilding lore, expanded examples |
| **Content Packs** | Additional settings, campaigns, creature collections, pre-built Mundi environments |
| **Mundi et Caeli Grystis** | The full 3D tabletop + real-time authoring tool |

### Why This Model?

```
┌────────────────────────────────────────────────────┐
│ THE FUNNEL                                         │
│                                                    │
│  Free PDA + Rules                                  │
│  ↓                                                 │
│  Players learn the system, fall in love           │
│  ↓                                                 │
│  Some buy physical book for art/lore              │
│  Some buy Mundi for 3D experience                 │
│  Some buy content packs for more adventures       │
│  ↓                                                 │
│  Everyone can still play together                 │
│  (Free players aren't locked out)                 │
└────────────────────────────────────────────────────┘
```

**Key insight:** A player with only PDA and a player with the full suite can be in the same session. Paid content enhances the experience but never fragments the playerbase.

### PDA vs Mundi: What's the Difference?

| Feature | PDA (Free) | Mundi (Paid) |
|---------|------------|--------------|
| Character sheets | ✓ | — (uses PDA) |
| Momentum tracking | ✓ | ✓ (synced) |
| DM dashboard | ✓ | ✓ (synced) |
| Basic 3D tactical view | ✓ | — |
| Position markers | ✓ | ✓ |
| Rulers & AoE templates | ✓ | ✓ |
| Full 3D environments | — | ✓ |
| Sketch-to-3D authoring | — | ✓ |
| Real-time world creation | — | ✓ |
| Physics & destruction | — | ✓ |
| Volumetric fog of war | — | ✓ |

PDA gives you a functional tactical map. Mundi gives you a living world.
