## Alternatives Considered

| System | Pros | Cons |
|--------|------|------|
| d20 + mod vs DC | Familiar, swingy, heroic | Very random, modifier treadmill |
| 2d6 + mod (PbtA) | Bell curve, partial success built-in | Narrow range |
| Dice Pool (count successes) | Tactile, scalable | Lots of dice, counting |
| d100 / Percentile | Intuitive odds | Can feel clinical |
| Step Dice (d4→d6→d8...) | Shows progression clearly | Odd probability curves |
| Diceless | Pure narrative | Some players want randomness |
| Cards | Unique feel, hand management | Need to carry cards |
