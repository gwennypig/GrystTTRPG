# Tags

Tags define what something IS and what it CAN DO. They appear on Gambits, Modules, and Loculi.

---

## Modifier

### <span style="color:#9d64f2">[INTERVENTVS]</span> / Intervention

A gambit tagged with INTERVENTVS allows it to be chosen when you would have momentum priority during the stack even if you should have been passed over due to not having COOPERATION with the pivotal party.
Many gambits tagged with INTERVENTVS also create an OCCĀSIŌ TURBIDA.

### <span style="color:#00ff11">[INFALLIBILIS]</span> / Infallible

An [<span style="color:#00ff11;font-weight:600">[INFALLIBILIS]</span>](Tags.md#infallibilis) [<span style="color:#70e697;font-weight:600">GAMBIT</span>](Dictionary.md#gambit) cannot [<span style="color:#ff0000;font-weight:600">ClCa</span>](Dictionary.md#clca) (fail or critical fail). It can still [<span style="color:#ffea00;font-weight:600">TRIVMPHVS</span>](Dictionary.md#trivmphvs), as opposed to [<span style="color:#000000;font-weight:600">[ABSOLUTUM]</span>](Tags.md#absolutum), which can only [<span style="color:#00ff7b;font-weight:600">SVCCVSSVS</span>](Dictionary.md#svccvssvs).

### <span style="color:#30fd89">[SIMPLEX]</span> / Simple

 SIMPLEX denotes the tagged as a simpler concept. For example, gambits that are simple don't require as much mental stack. Gambits that are defined as SIMPLEX benefit from many boons that support SIMPLEX Gambits.

### <span style="color:#000000">[ABSOLUTUM]</span> / Absolute

This Gambit does not require a check. It always results in SUCCESSUS.

### <span style="color:#0004ff">[CARDINALIS]</span> / Pivotal

A pivotal gambit cannot be chosen as an ADDON.

## Form

### <span style="color:#ee5858">[TELUM]</span> / Missile

Ranged armament, whether that be a plasma rifle, old timey six shooter, A WALKER's shoulder missiles, a javelin, a bow.
