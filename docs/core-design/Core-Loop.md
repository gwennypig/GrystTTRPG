# Core Loop

#ttrpg #design #core

The **core loop** is what players actually DO during a session, repeated until the session ends.

## The Basic Loop

```
┌─────────────────────────────────────────┐
│                                         │
│  1. [SITUATION] → 2. [DECISION] →      │
│                                         │
│  3. [RESOLUTION] → 4. [CONSEQUENCE]    │
│         ↓                               │
│    (loop back)                          │
│                                         │
└─────────────────────────────────────────┘
```

### 1. Situation
*How do players encounter problems/opportunities?*

### 2. Decision
*What meaningful choices do players make?*

### 3. Resolution
*How do we determine what happens? (Dice? Cards? Narrative?)*

### 4. Consequence
*How does the outcome change the fiction/game state?*

## Example Loops from Other Games

**D&D:** Explore → Encounter threat → Combat/Social → Loot/Story → Explore...

**Blades in the Dark:** Get Job → Plan (briefly) → Score → Payoff/Heat → Downtime → Get Job...

**Monster of the Week:** Hook → Investigate → Discover weakness → Showdown → Aftermath...

---
*Your loop should be completable multiple times per session.*
